# Merchant-Upload-Batch-File

A full-stack web system that allows merchants to upload batch payment files and manage profile details.  In future, will add the auto encryption function by using RSA and AES encryption method.
Developed using **Angular 19.2.15** for the frontend and **Spring Boot 3.5.3** for the backend.

---

## 🧭 Getting Started

Before starting, make sure you have installed the following:

- **Java 17 or above**
- **Node.js 18+ and npm**
- **Maven 3.9+**
- **Angular CLI 19.2.15** (`npm install -g @angular/cli`)
- *(Optional)* **MySQL 8.x** if you want to use a persistent database
---


## Step 1: Start the Spring Boot Server

First, open a terminal in the `RTAbackend` folder and run:

```power shell
# Navigate to backend folder
cd RTAbackend

# Run Spring Boot app
mvn spring-boot:run

---

## Step 2: Start the Spring Boot Server

# Navigate to frontend folder
